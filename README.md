# 🍽️ Restaurant Customer Data Analysis

A data analysis project built with Python, Pandas, and NumPy that cleans, explores, and analyzes restaurant customer data to uncover useful patterns and insights.

## Overview

Raw data is rarely ready to use. This project takes restaurant customer datasets in CSV format and works through the full analysis workflow: cleaning and preprocessing the data, performing exploratory data analysis (EDA), and extracting meaningful insights using statistical analysis. The goal is to turn raw, messy data into structured, easy-to-interpret information that supports better decision-making.

## Objectives

- Clean and prepare raw customer data for analysis
- Explore the data to understand trends and patterns
- Extract insights that can support business decisions
- Improve data accuracy and reliability

## Key Features

- **Data cleaning:** handles missing values, duplicate records, and inconsistent data formats.
- **Preprocessing:** transforms raw data into a structured, analysis-ready format.
- **Exploratory Data Analysis (EDA):** examines distributions, trends, and relationships in the data.
- **Data manipulation with Pandas:** filtering, sorting, grouping, merging, and aggregation.
- **Statistical analysis:** summarizes the data using NumPy and descriptive statistics.

## Tech Stack

- **Language:** Python 3
- **Libraries:** Pandas, NumPy
- **Environment:** Jupyter Notebook
- **Data format:** CSV

## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook

### Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Zaara-Abrar/<your-repo-name>.git
   ```
2. Navigate to the project folder:
   ```bash
   cd <your-repo-name>
   ```
3. Install the required libraries:
   ```bash
   pip install pandas numpy notebook
   ```
4. Launch Jupyter Notebook and open the analysis file:
   ```bash
   jupyter notebook
   ```

> Replace `<your-repo-name>` with your actual repository name.

## Analysis Workflow

1. **Load the data:** read the CSV file(s) into Pandas DataFrames.
2. **Clean the data:** fix missing values, remove duplicates, and standardize formats.
3. **Explore the data:** use filtering, sorting, and grouping to understand the dataset.
4. **Combine and aggregate:** merge datasets and compute summaries.
5. **Analyze and interpret:** apply statistical analysis to draw insights.
